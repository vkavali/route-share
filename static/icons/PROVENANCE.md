# Icon provenance

These assets come from the pinned [`@phosphor-icons/core` 2.1.1 package](https://www.npmjs.com/package/@phosphor-icons/core/v/2.1.1), published by the Phosphor Icons project at [phosphor-icons/phosphor-core](https://github.com/phosphor-icons/phosphor-core). The package declares the MIT license; its license text is included in [`LICENSE.txt`](./LICENSE.txt).

The standalone SVGs under `fill/` and `regular/` are copied from that release without path edits. [`../icons.js`](../icons.js) embeds those exact SVG strings and adds only caller-selected size, class, and accessibility attributes to the outer `<svg>` element.

The filled set follows the approved solid-icon direction for home, vehicle, steering wheel, users, settings, pin, lock, star, phone, warning, navigation, and stack symbols. The regular set is used for maps, search, arrows, visibility, crosshair, chat, list, calendar, and path symbols.
